## Typography Framework

### Primary Typography Stack

#### Headings: Academic Heritage
- **Primary Choice:** Georgia (serif, literary heritage)
- **Alternative:** Times New Roman (classic academic)
- **Web Font:** Source Serif Pro (modern academic with good screen rendering)
- **Rationale:** Conveys scholarly authority and literary tradition

#### Body Text: Academic Readability
- **Primary Choice:** Source Sans Pro (clean, academic)
- **Alternative:** Open Sans (approachable academic)
- **Rationale:** Professional readability for extended academic-style content
- **Specifications:** 
  - Minimum 18px base size (accessibility for academic reading)
  - Line height 1.6+ (academic content standards)
  - Letter spacing: normal (maintaining readability)

#### Code/Technical: Precision
- **Primary Choice:** Source Code Pro
- **Usage:** Technical citations, data references, code examples
- **Rationale:** Academic precision for technical content

### Typography Hierarchy

#### Academic Content Structure
```
H1: 2.5rem (40px) - Georgia Bold - Chapter titles, main headings
H2: 2rem (32px) - Georgia Semibold - Major sections
H3: 1.5rem (24px) - Georgia Regular - Subsections
H4: 1.25rem (20px) - Source Sans Pro Semibold - Supporting sections
Body: 1.125rem (18px) - Source Sans Pro Regular - Main content
Caption: 1rem (16px) - Source Sans Pro Regular - Supporting text
```

#### Academic Citation Standards
```
Footnotes: 0.875rem (14px) - Source Sans Pro Regular
References: 1rem (16px) - Source Sans Pro Regular
Block Quotes: 1.125rem (18px) - Georgia Italic
```
